# Bank Management System Using Hibernate
## Objective

The objective of this project is to develop a Bank Management System that manages banking operations efficiently using Hibernate ORM and PostgreSQL database. The system helps in handling customer accounts, transactions, deposits, withdrawals, and fund transfers while ensuring secure and structured data management.

## Tools & Technologies
Language: Java
Framework: Hibernate ORM
Database: PostgreSQL
IDE: Eclipse
Connectivity: JDBC
Build Tool: Maven (if used)
